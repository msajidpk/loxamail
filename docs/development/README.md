# Development

Use npm and the project's local Next.js 16 setup. Database work must use a new local MariaDB database; the prior LoxaMail database is not to be reused. Staging and production databases must remain separate. Read `LOXAMAIL_MASTER_SPEC.md` before starting work.

The implemented Prisma foundation, local environment setup, and remaining database-layer integrity responsibilities are documented in [Database Foundation V1](database-foundation-v1.md).
