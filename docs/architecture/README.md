# Architecture

The approved direction is a product-independent modular monolith using Next.js server architecture. The unified Customer Account model and future provider abstraction requirements are in `LOXAMAIL_MASTER_SPEC.md`. Update the Master Spec when an architecture decision is approved.

The [Master Architecture Review V1](master-architecture-review-v1.md) records the consistency review and readiness assessment for beginning conceptual database architecture.

The [Database Architecture V1](database-architecture-v1.md) defines the conceptual entities, ownership, relationships, snapshots, constraints, and implementation boundary for the single-database modular monolith.
